# مجلد الشعارات والصور

احفظي الصور المرفقة هنا بهذه الأسماء بالضبط:

1. شعار مجمع الموسى (الصورة البنفسجية) ← احفظيها باسم:
   assets/almousa-logo.png

2. شعار جمعية تعلّم (الأخضر) ← احفظيها باسم:
   assets/taallam-logo.png

3. باركود موقع الدار (QR) ← احفظيه باسم:
   assets/location-qr.png

بعد الحفظ حدّثي الصفحة وستظهر الصور تلقائياً في الهيدر وقسم عن الدار والفوتر وقسم التواصل.
